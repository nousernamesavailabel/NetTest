Local Users (0)

Local accounts log in directly against this dashboard — no external RADIUS server needed. Passwords are stored as salted hashes, never in plaintext. Admin accounts can do everything; read-only accounts can view results, compare runs and run the browser speed test, but can't run path tests, edit notes or open Config. To update an existing user, enter its username — leave the password blank to keep it.
